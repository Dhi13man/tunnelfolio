# Support

Use GitHub Issues for reproducible bugs and focused feature requests. Include the
release version, Linux distribution, architecture, systemd version, relevant
OpenVPN or WireGuard tools version, redacted service status, and exact steps.

Do not post profiles, private keys, credentials, hostnames, or public IP
addresses. Security reports belong in GitHub's private vulnerability reporting,
as described in [SECURITY.md](SECURITY.md).

There is no guaranteed response time or private deployment support.
